## 1. 한 줄 요약

기능(v5.3 탭 정리·지표 정합)은 갖춰졌으나, **지도는 카드 안 inset 지도**이고 **전략은 인사이트 카드 벽 + KPI 카드 그리드**라서 Harbor Clinical의 “한 구성·한 목적·실시각 앵커”가 깨져 있습니다.  
**지도 = 풀블리드 분석면**, **전략 = 인사이트 우선 스토리 레이아웃**으로 개편합니다.

## 2. 현재 실측 (코드 기준)

### 2.1 지도 분석 (`app/dashboard/map/page.tsx` ~963줄)

| 영역 | 현황 | 디자인 문제 |
|------|------|-------------|
| 페이지 골격 | container → 제목/배지 → 필터 Card → 시각화 버튼 → Tabs → Select → **12컬럼 Card(지도9+통계3)** → 상세 Card | 컨트롤이 세로로 쌓여 **첫 화면에서 지도가 작음** |
| 지도 | `Card` + `CardHeader` + `p-6` 안 Leaflet `h-[500px]` | inset 카드형 지도 — 공간 분석의 시각 앵커가 약함 |
| 통계 | 우측 Card에 합계/평균/최대/지역수 + Top5 | 카드 중첩, 숫자 계층 약함, 클릭 가능함이 드러나지 않음 |
| 상세 | 지도 **아래** 별도 Card | 선택 후 스크롤 필요, 지도 맥락 단절 |
| 색 | shadcn 기본 + 모드 버튼 default/outline | Harbor teal 토큰 미활용, 범례 없음 |
| 모바일 | Tabs 2×2, 지도·통계 세로 스택 | 툴바·셀렉트가 지도보다 먼저 공간을 차지 |

### 2.2 경영·마케팅 인사이트 (`/dashboard/strategy`)

| 영역 | 현황 | 디자인 문제 |
|------|------|-------------|
| 첫 뷰포트 | `ManagementInsights` 카드 목록이 **탭보다 위**에 고정 | 인사이트 N개가 카드 벽 → “한 구성” 위반, 경영 요약보다 경고문 먼저 |
| 경영 요약 | KPI Card 4장 + Top 지역/질병 Card | 대시보드와 동일한 카드 그리드 클리셰 |
| 탭 | 7탭 `flex-wrap` + `text-xs` 아이콘 | wrap 시 2줄, 활성 상태 약함, 모바일 스와이프 없음 |
| 탭 내부 | Flow·RFM·Cohort·Journey 등 **세로 Card 스택** | 섹션 목적 불명확, 스크롤 피로 |
| 인사이트 색 | `red/yellow/blue/green-50` 하드코딩 | Harbor `--danger/--warning/--positive`와 불일치 |
| 근거 배지 | `rounded-full` pill | 사용자 규칙상 pill 남발 지양 |

### 2.3 공통 (v5.0 Harbor Clinical과의 갭)

- 토큰·폰트는 앱 셸에 적용됐으나 **지도·전략 본문은 여전히 “기본 shadcn 대시보드”**
- 지도↔전략 지역 스토리가 **시각적으로 연결되지 않음** (필터만 공유)
- 모션: KPI/레이어 전환에 settle 모션 없음

## 3. 디자인 방향: **Harbor Clinical — Analysis Surfaces**

브랜드·색·타이포는 v5.0 Harbor Clinical을 **유지·연장**. 새 테마를 만들지 않습니다.

### 3.1 원칙 (이 두 화면에만 적용)

1. **지도는 면(plane), 카드는 상호작용 컨테이너만**  
   - 지도: 풀블리드(또는 거의 edge-to-edge) 분석면  
   - Card: 필터 시트, 통계 레일, 인사이트 액션 블록에만
2. **첫 뷰포트 = 한 일**  
   - 지도: 지도 + 최소 툴바 + 얇은 통계 레일  
   - 전략: **오늘의 우선 인사이트 1~3** + 탭 (KPI 그리드는 탭 안으로)
3. **한 섹션·한 헤드라인**  
   - 전략 탭 안 패널을 “제목 없는 Card 연속”에서 “섹션 헤더 + 본문”으로
4. **실시각 앵커**  
   - 지도: OSM 타일 자체가 앵커  
   - 전략: 인사이트 문장 + 근거 수준이 앵커 (아이콘 장식 최소화)
5. **클리셰 금지**  
   - 퍼플/글로우/다크모드 기본/이모지/플로팅 배지/히어로 위 칩 금지  
   - KPI 4카드 그리드는 축소 또는 메트릭 스트립으로 대체

### 3.2 색·표현 (지도·인사이트 전용)

| 용도 | 토큰/표현 |
|------|-----------|
| 선택 지역 | `--brand` 스트로크/하이라이트 |
| 재방문율 높음 | `--positive` 계열 스케일 |
| 재방문율 낮음 / critical | `--danger` / `--warning` |
| 히트맵 | teal→amber 단색 ramp (레인보우 금지) |
| 인사이트 critical/warning/success/info | 좌측 3px accent bar + 배경 `surface-2` (색면 Card 전체 칠하기 축소) |

### 3.3 모션 (2–3개만)

1. 지도 레이어/탭 전환: 통계 레일 숫자 opacity settle (~200ms)  
2. 지역 선택: 상세 패널 slide-in (우측 또는 하단 시트)  
3. 전략 인사이트: 우선순위 1건만 살짝 fade-up (나머지 즉시)

`prefers-reduced-motion` 존중.

## 4. 화면별 개편안

### 4.1 지도 분석 — **Map Canvas Layout**

```
┌─────────────────────────────────────────────────────────────┐
│ [분포|재방문|임상|인구]  [지표▾]  [마커|원|히트]  [필터]     │  ← sticky 툴바 (1줄)
├──────────────────────────────────────────────┬──────────────┤
│                                              │ 합계 · 평균  │
│           FULL MAP (카드 래퍼 제거)            │ Top 5 클릭   │
│           범례(미니) 좌하단                   │ 가능 리스트  │
│                                              │              │
├──────────────────────────────────────────────┴──────────────┤
│ (선택 시) 하단/우측 Sheet: 지역 상세 — KPI 스트립 + Top질병   │
└─────────────────────────────────────────────────────────────┘
```

**구체 변경**

| ID | 변경 | 성공 기준 |
|----|------|-----------|
| M1 | 지도 Card/`p-6` 제거 → `rounded-none` 또는 얇은 border plane, 높이 `min-h-[70vh]` | 첫 뷰포트에서 지도가 주인공 |
| M2 | 제목·배지·시각화·탭·Select를 **단일 sticky 툴바**로 통합 | 컨트롤 세로 스택 해소 |
| M3 | 통계 Card → **사이드 레일** (배경 `surface`, border-l만) | 카드 중첩 1단계 감소 |
| M4 | Top5·지역 클릭 = 지도 flyTo와 동일 피드백(호버 underline) | 리스트가 조작 UI로 인식 |
| M5 | 지역 상세를 하단 Card → **Sheet/Drawer** (닫기 명확) | 스크롤 없이 맥락 유지 |
| M6 | 히트맵/원형 범례 미니 블록 | 색 의미 즉시 이해 |
| M7 | 임상 미선택 empty state: 중앙 짧은 안내 + Select 포커스 유도 | “빈 회색 박스” 탈피 |
| M8 | 모바일: 통계 레일 → 지도 위 접히는 바 / Top5는 바텀시트 | 375px에서 지도 ≥50vh |

**건드리지 않음**: `map-metrics`, 4탭 의미, Leaflet 엔진, 필터 로직.

### 4.2 경영·마케팅 인사이트 — **Insight Brief Layout**

```
┌─────────────────────────────────────────────────────────────┐
│ 경영·마케팅 전략          샘플·윈도우·N건 (메타 1줄)          │
├─────────────────────────────────────────────────────────────┤
│ ★ 우선 인사이트 (최대 3)  — accent bar, 근거 배지(사각)       │  ← 첫 뷰포트 핵심
│   [나머지 N건 펼치기]                                        │
├─────────────────────────────────────────────────────────────┤
│ 세그먼트 네비: 경영 | 유입·유지 | 지역 | 임상 | … (스크롤탭) │
├─────────────────────────────────────────────────────────────┤
│ 탭 본문: 메트릭 스트립(카드4 대체) → 섹션 1 → 섹션 2 …       │
└─────────────────────────────────────────────────────────────┘
```

**구체 변경**

| ID | 변경 | 성공 기준 |
|----|------|-----------|
| S1 | `ManagementInsights`를 “전체 목록 Card” → **우선 3 + 접기** | 첫 뷰포트가 인사이트 브리핑 |
| S2 | 카테고리 색면 Card → **좌측 accent bar** + surface | Harbor 토큰, 덜 요란함 |
| S3 | 근거 `rounded-full` → **작은 사각 배지** (`rounded-sm`) | pill 축소 |
| S4 | Executive KPI 4 Card → **메트릭 스트립** (구분선, tabular-nums) | 카드 그리드 클리셰 제거 |
| S5 | TabsList wrap → **가로 스크롤 세그먼트** (활성 = brand underline) | 2줄 wrap 제거 |
| S6 | 탭 내부: 패널마다 `h2` + 한 문장 설명, Card는 차트/테이블에만 | 한 섹션·한 목적 |
| S7 | 유입·유지 탭: Flow / RFM / Cohort / Journey를 **서브앵커 네비**로 | 무한 스크롤 완화 |
| S8 | 지역 탭: “지도에서 보기” 링크 (`/dashboard/map?tab=…`) | 지도·전략 시각 연결 |
| S9 | Lightbulb 장식 아이콘 축소 — 제목 타이포로 계층 | 장식 의존 감소 |

**건드리지 않음**: `buildManagementInsights` 로직, 7탭 구성(기능), RFM/Cohort 계산.  
(탭 축소는 v5.2 Round B 기능 과제 — **이번 디자인 PR과 분리**)
