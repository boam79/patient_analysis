# UI·UX 고도화 제안 v5.7 — Planner

**작성일**: 2026-07-24  
**모드**: Planner (구현은 Executor 승인 후)  
**브랜드 방향**: Harbor Clinical (deep teal `#0B6E6E` + cool mist) 유지·심화

---

## 1. 현재 상태 요약

v5.0~5.6에서 토큰·랜딩·Admin IA·메트릭 스트립까지 정비됨. 남은 UX 병목은 **정보 밀도**, **필터 조작 비용**, **화면 전환 단절**, **모바일 필터**, **첫 실행 유도**다.

| 영역 | 현재 | 문제 |
|------|------|------|
| 대시보드 | KPI + 다수 차트/지도 세로 스택 | 스크롤 벽, 인사이트보다 차트 나열 |
| 필터 | 페이지 상단 `FilterPanel` 카드 | 스크롤 시 소실, 칩·적용 피드백 약함 |
| 지도/전략 | 별도 라우트 | 맥락 끊김, brushing 일부만 연동 |
| 모바일 | 헤더 햄버거 + 필터 카드 전체 | 한 손 조작·필터 시트 부재 |
| 온보딩 | 랜딩 CTA → 업로드 | 단계 안내·검증 피드백 약함 |

---

## 2. 제안 방향 (4개 시안)

### A. Insight-First Dashboard
- 상단: sticky **필터 칩 바** (기간/윈도우/지역… + `+ 필터`)
- 본문: **한 줄 인사이트** → MetricStrip → 지도+핵심 차트 2개만 1뷰포트
- 나머지 차트는 탭/아코디언으로 뒤로

### B. Analysis Workspace (지도+차트 분할)
- 좌: 필터 드로어 / 우: `지도+차트 | 차트만 | 지도만`
- 지역 선택 시 지도·막대 **크로스 하이라이트** 강화

### C. Mobile: 하단 탭 + 필터 바텀시트
- 하단 4탭 (대시보드/지도/전략/더보기)
- FAB 또는 칩 → 바텀시트 Apply

### D. Guided Onboarding
- 히어로: 업로드 / 샘플 둘러보기
- `업로드 → 검증 → 대시보드` 미니멀 스텝

## 3. 우선순위 (구현 시)

| ID | 항목 | 영향 | 침습도 |
|----|------|------|--------|
| Ux1 | Sticky 필터 칩 바 + 패널을 드로어/시트로 | 높음 | 중 |
| Ux2 | 대시보드 1뷰포트 인사이트+핵심 2차트 | 높음 | 중 |
| Ux3 | Workspace 뷰 모드 (지도/차트 분할) | 중 | 중~고 |
| Ux4 | 모바일 하단 탭 + 필터 바텀시트 | 높음 | 중 |
| Ux5 | 업로드 온보딩 스텝·검증 UI | 중 | 낮음 |
| Ux6 | 빈/로딩/에러 상태 카피·스켈레톤 통일 | 중 | 낮음 |

**비목표**: 차트 라이브러리 교체, 분석 로직 변경, Admin 기능 확장.

## 4. 성공 기준 (Executor 검증용)

1. 데스크톱 대시보드: 스크롤 없이 KPI+인사이트+지도(또는 차트2) 인지 가능 (1440px)
2. 필터 변경 후 칩 바에 활성 필터가 항상 보임
3. 375px: 하단 탭으로 주요 3화면 이동, 필터는 시트에서 Apply
4. 신규 사용자: 샘플 CTA 3탭 이내 대시보드 도달
5. Harbor Clinical 토큰 유지 (퍼플/크림세리프/다크글로우 금지)
