# 일반 사용자 로그인 기능 활성화 가이드

## 현재 상태

일반 사용자 로그인 페이지(`/login`)는 구현되어 있으나, **실제 사용은 비활성화 상태**입니다.

## 구현된 기능

1. **로그인 페이지**: `app/login/page.tsx`
   - 이메일/비밀번호 로그인
   - 승인 상태 확인
   - ADMIN 자동 리다이렉트
   - 미승인 사용자 안내

2. **Middleware 접근 제어**: `lib/supabase/middleware.ts`
   - `/dashboard` 접근 시 승인된 사용자만 허용
   - ADMIN은 `/admin`으로 자동 리다이렉트
   - 미승인 사용자는 로그인 페이지로 리다이렉트

## 활성화 방법

현재는 **기능만 구현**되어 있으며, 실제로는 다음 중 하나의 방법으로 활성화할 수 있습니다:

### 방법 1: 자동 활성화 (현재 상태)

현재 middleware가 이미 `/dashboard` 접근 시 로그인 및 승인을 확인하므로, 
사용자가 `/login` 페이지에 접근하여 로그인하면 자동으로 작동합니다.

### 방법 2: 루트 경로에서 로그인 강제

루트 경로(`/`)에서 로그인하지 않은 사용자를 `/login`으로 리다이렉트하려면:

```typescript
// lib/supabase/middleware.ts의 updateSession 함수에 추가
if (pathname === '/' && !user) {
  const url = request.nextUrl.clone()
  url.pathname = '/login'
  return NextResponse.redirect(url)
}
```

### 방법 3: 대시보드 접근 시 로그인 페이지로 리다이렉트

현재는 이미 구현되어 있습니다. 미로그인 사용자가 `/dashboard`에 접근하면 자동으로 `/login`으로 리다이렉트됩니다.

## 테스트 방법

1. **승인된 일반 사용자로 로그인**:
   ```
   - /login 페이지 접근
   - 이메일/비밀번호 입력
   - 로그인 성공 시 /dashboard로 리다이렉트
   ```

2. **미승인 사용자 테스트**:
   ```
   - /login 페이지 접근
   - 미승인 계정으로 로그인 시도
   - "승인 대기 중" 메시지 표시
   ```

3. **ADMIN 사용자 테스트**:
   ```
   - /login 페이지 접근
   - ADMIN 계정으로 로그인
   - 자동으로 /admin으로 리다이렉트
   ```

## 주의사항

- 현재 `/login` 페이지는 접근 가능하지만, 루트 경로(`/`)는 여전히 공개 접근 가능합니다.
- 메인 대시보드(`/dashboard`)는 로그인 및 승인 필수입니다.
- 제작자 페이지(`/admin`)는 ADMIN 역할 및 승인 필수입니다.
