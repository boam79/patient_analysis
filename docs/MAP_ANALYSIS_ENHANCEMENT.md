# 지도 분석 페이지 고도화 제안서

## 📋 배경 및 목적

현재 지도 분석 페이지는 4개 탭(신환/재환/환자수/재방문율)과 마커 모드만 제공하고 있습니다. 더 다양한 데이터 시각화와 분석 기능을 추가하여 사용자가 공간 데이터를 더 깊이 있게 탐색할 수 있도록 개선합니다.

---

## 🎯 제안 기능

### 1. 시각화 모드 확장

#### 1.1 히트맵 모드 추가
- **현재**: 마커 모드만 제공
- **제안**: 히트맵 모드 추가 (Leaflet.heat 활용)
- **효과**: 
  - 밀집도 패턴을 한눈에 파악
  - 색상 강도로 값의 크기 표현
  - 대용량 데이터 시각화에 유리

#### 1.2 클러스터 모드 추가
- **기능**: 마커를 그룹화하여 표시 (Leaflet.markercluster)
- **효과**:
  - 줌 레벨에 따라 자동 그룹화
  - 성능 향상 (1000+ 마커 처리)
  - 지역별 집계값 표시

#### 1.3 원형 차트 마커 (Circle Marker)
- **기능**: 마커 크기로 값 표현
- **효과**:
  - 값의 크기를 직관적으로 비교
  - 색상 + 크기로 2차원 정보 표현

#### 1.4 시각화 모드 전환 버튼
- **UI**: 지도 상단에 토글 버튼
- **옵션**: 마커 / 히트맵 / 클러스터 / 원형

---

### 2. 추가 분석 탭

#### 2.1 질병별 분포
- **기능**: 
  - Top 10 질병별 지역 분포
  - 질병 선택 드롭다운
  - 질병별 색상 구분
- **데이터**: `rawData`에서 질병별 지역 집계

#### 2.2 수술별 분포
- **기능**:
  - Top 10 수술별 지역 분포
  - 수술 선택 드롭다운
  - 수술 건수 표시
- **데이터**: `rawData`에서 수술별 지역 집계

#### 2.3 연령대별 분포
- **기능**:
  - 연령대별 환자 분포 (10대 이하 ~ 70대 이상)
  - 연령대 선택 드롭다운
  - 연령대별 색상 그라데이션
- **데이터**: `rawData`에서 연령대별 지역 집계

#### 2.4 성별 분포
- **기능**:
  - 남성/여성 비율을 원형 차트로 표시
  - 각 지역별 성별 비율
- **데이터**: `rawData`에서 성별별 지역 집계

#### 2.5 월별 트렌드 (시간 애니메이션)
- **기능**:
  - 시간 슬라이더로 월별 데이터 탐색
  - 재생/일시정지 버튼
  - 애니메이션으로 변화 추이 확인
- **데이터**: `rawData`에서 월별 지역 집계

---

### 3. 통계 패널 확장

#### 3.1 Top 5 지역 리스트
- **기능**:
  - 현재 탭 기준 Top 5 지역 표시
  - 클릭 시 해당 지역으로 지도 이동
  - 값과 비율 표시

#### 3.2 트렌드 그래프
- **기능**:
  - 선택된 지역의 시간별 추이
  - 미니 라인 차트 (Recharts)
  - 월별/분기별 전환

#### 3.3 상관관계 분석
- **기능**:
  - 환자수 vs 재방문율 산점도
  - 신환 vs 재환 비율
  - 지역별 비교

#### 3.4 상세 정보 패널
- **기능**:
  - 지역 클릭 시 상세 정보 표시
  - Top 5 질병/수술
  - 평균 연령, 성별 비율
  - 재방문 통계

---

### 4. 인터랙티브 기능

#### 4.1 필터 패널 통합
- **기능**:
  - 지도 페이지에 필터 패널 추가
  - 필터 변경 시 지도 즉시 업데이트
  - 필터 상태 표시

#### 4.2 지역 비교 모드
- **기능**:
  - 2개 지역 동시 선택
  - 사이드바에 비교 통계 표시
  - 차이값 하이라이트

#### 4.3 범위 선택 도구
- **기능**:
  - 사각형/원형 영역 선택
  - 선택 영역 내 통계 집계
  - 선택 영역 내 환자 리스트

#### 4.4 지도 레이어 컨트롤
- **기능**:
  - 여러 데이터 레이어 동시 표시
  - 레이어 on/off 토글
  - 투명도 조절

---

### 5. 고급 분석 기능

#### 5.1 핫스팟 분석
- **기능**:
  - 통계적으로 유의한 핫스팟 표시
  - Getis-Ord Gi* 통계 활용
  - 핫스팟/콜드스팟 구분

#### 5.2 밀도 등고선
- **기능**:
  - 환자 밀도 등고선 표시
  - 등고선 간격 조절
  - 색상 그라데이션

#### 5.3 이동 경로 분석
- **기능**:
  - 환자별 방문 경로 시각화
  - 화살표로 이동 방향 표시
  - 자주 이동하는 경로 하이라이트
