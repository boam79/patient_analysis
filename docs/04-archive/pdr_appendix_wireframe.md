## 🧭 1️⃣ 전체 정보 구조 (Information Architecture)

```
📊 대시보드 홈
 ├── 데이터 업로드 & 프리뷰 (파일 드롭존)
 ├── 전역 필터 바 (기간·질병·연령·성별·지역)
 ├── 3대 분석 축
 │    ├── 재방문 중심 축
 │    ├── 공간 중심 축 (지도)
 │    └── 질병 중심 축
 ├── 하단 분석 탭
 │    ├── Trend (기간별 추세)
 │    ├── Boundary (지역 비교)
 │    └── Table (데이터 표)
 ├── 보고서 / 캡처 / 로그 관리
 └── 설정 (매핑파일, 로컬 저장, 테마)
```

## 🧩 2️⃣ 화면 구성 (Wireframe Layouts)

### 📍 2.1 상단 구조 (Header / Global Filter)

```
──────────────────────────────────────────────
[로고]  [데이터셋명 ▼]  [업로드 버튼]
기간 ▼  |  윈도우 30/90/180  |  질병 ▼  |  연령 ▼  |  성별 ▼  |  지역 ▼
[보고서(.md)] [PNG 캡처] [설정 ⚙️]
──────────────────────────────────────────────
```

### 🧮 2.2 메인 대시보드 3열 레이아웃

```
┌──────────────────────┬──────────────────────────┬──────────────────────┐
│ [왼 패널]            │ [중앙 지도/차트]         │ [오른 패널]          │
│──────────────────────│──────────────────────────│──────────────────────│
│ - 질병 Top 10 막대   │ - 히트맵(밀집/재방문율) │ - 선택 지역 상세 카드│
│ - 연령 피라미드      │ - 마커(Top 지역)         │ - KPI 카드(4개)     │
│ - 이탈 질병 리스트   │ - 범례/모드 토글         │ - 주요 연령대 차트   │
│   (재방문↓ 질병군)   │ - 반경 설정 슬라이더     │ - 자동 인사이트 문장 │
└──────────────────────┴──────────────────────────┴──────────────────────┘
```

### 🔄 2.3 하단 탭 구조 (Trend / Boundary / Table)

#### 🔹 Trend 탭
```
──────────────────────────────
[Trend] 월별 / 분기별 / 연도별
──────────────────────────────
│ Line Chart (재방문율)
│ Bar Chart (신규 vs 재방문)
│ 요약 인사이트: “무릎관절증 ↑7.2pp”
──────────────────────────────
```

#### 🔹 Boundary 탭
```
──────────────────────────────
[Boundary] 시/군/구 비교
──────────────────────────────
│ 지도 윤곽 강조 (선택 지역)
│ Bar Chart: 지역별 재방문율
│ Boxplot: 지역별 환자 분포
│ 태그: [밀집↑/재방문↓] 등
──────────────────────────────
```

#### 🔹 Table 탭
```
──────────────────────────────
[Table] 요약 집계표
──────────────────────────────
│ 질병 | 연령대 | 환자수 | 재방문율 | 지역 | 평균 간격 |
│ 정렬, 필터, 내보내기(CSV)
──────────────────────────────
```

## 🧭 3️⃣ 주요 인터랙션 시나리오

| 시나리오 | 인터랙션 설명 | 결과 |
|-----------|----------------|------|
| 📁 파일 업로드 | 드롭존 클릭 또는 드래그 | 50행 프리뷰 표시 (1.5초 내) |
| ⚙️ 데이터 정제 | 자동 ICD·주소 매핑 | 품질 배지 표시 (인식률%) |
| 📊 질병 클릭 | 막대 그래프 선택 | 지도·카드 동기화 |
| 🗺️ 지도 클릭 | 마커/지역 클릭 | 오른쪽 상세 카드 갱신 |
| 📅 기간 변경 | 필터 드롭다운 조작 | 모든 차트 리렌더 |
| 🧾 보고서 생성 | 클릭 시 팝업 → 섹션 선택 | Markdown 파일 다운로드 |
| 📸 PNG 캡처 | 대상 선택 후 캡처 | 파일 자동 저장 (워터마크 포함) |
| 🧩 매핑 관리 | “저장된 매핑 보기” | 버전·삭제·내보내기 가능 |

## 🧱 4️⃣ 시각 스타일 가이드 (Style Guide)

| 요소 | 권장 디자인 |
|------|---------------|
| **컬러** | ColorBrewer 기반 (Red–Blue 대비), 히트맵: Yellow–Red |
| **폰트** | Inter / Pretendard (숫자 중심 폰트) |
| **간격** | 최소 16px 여백, 카드 사이 24px |
| **아이콘** | Lucide / Material Icons |
| **차트 스타일** | 부드러운 곡선, 음영·그리드 최소화 |
| **마스킹 표식** | n<5 → “·” 또는 “<5명” |
| **툴팁** | 값 + 단위 + 마스킹 여부 표시 |

## 📊 7️⃣ 출력 화면(내보내기) 구조

- 생성 시각: 2025-10-21 09:30
- 데이터셋: 2025_10_환자데이터.xlsx
- 필터: 질병=무릎관절증, 연령=60+, 기간=최근90일

## 1️⃣ 재방문 중심 분석
| 질병 | 환자수 | 재방문율 | 평균 간격 |
|------|--------|----------|-----------|

## 2️⃣ 공간 중심 분석
Top 지역: 인창동(45%), 교문동(39%)

## 3️⃣ 질병 중심 분석
이탈 질병 Top3: 요통, 고혈압, 당뇨

## 4️⃣ 요약
“무릎관절증 환자 재방문율 7.2pp 상승”

## ✅ 결론

이 와이어프레임 문서는 실제 개발 전 **시각적·구조적 청사진**으로 활용된다.  
Next.js 기반으로 빠른 데이터 분석·시각화를 목표로 하며,  
모든 데이터는 로컬에서 처리되어 **보안성과 속도**를 동시에 확보한다.
