# 문서 디렉토리 구조

이 디렉토리는 PDR Dashboard v4.1 프로젝트의 모든 문서를 포함합니다.

## 📁 디렉토리 구조

### 📋 01-proposals/ - 계획 및 제안서
프로젝트의 새로운 기능이나 개선사항에 대한 계획 및 제안서 문서들입니다.

- **AUTH_ADMIN_PROPOSAL.md**: Supabase 기반 인증/관리자 시스템 제안서
- **ANALYSIS_ENHANCEMENT_PROPOSAL.md**: 데이터 분석 고도화 제안서
- **MAP_ANALYSIS_ENHANCEMENT.md**: 지도 분석 고도화 제안서
- **PRODUCER_PAGE_PROJECT_PLAN.md**: 제작자 페이지 별도 프로젝트 구성 계획

### ✅ 02-completed/ - 완료 보고서
각 Phase별 완료 보고서 및 검증 완료 문서들입니다.

- **PHASE4_COMPLETE.md**: Phase 4 완료 보고서
- **PHASE5_COMPLETE.md**: Phase 5 완료 보고서
- **PHASE6_COMPLETE.md**: Phase 6 완료 보고서
- **PHASE7_COMPLETE.md**: Phase 7 완료 보고서
- **PHASE8_COMPLETE.md**: Phase 8 완료 보고서
- **PHASE9_COMPLETE.md**: Phase 9 완료 보고서
- **CHART_DATA_VERIFICATION_COMPLETE.md**: 차트 데이터 검증 완료 보고서
- **LOCAL_TEST_COMPLETE.md**: 로컬 테스트 완료 보고서

### 🚀 03-deployment/ - 배포 관련 문서
배포 가이드 및 배포 관련 문서들입니다.

- **DEPLOYMENT_GUIDE.md**: 일반 배포 가이드
- **DEPLOYMENT_TEST_GUIDE.md**: 배포 테스트 가이드
- **VERCEL_DEPLOYMENT_STEPS.md**: Vercel 배포 단계별 가이드
- **VERCEL_DEPLOY_READY.md**: Vercel 배포 준비 완료 문서
- **PHASE4_DEPLOYMENT_READY.md**: Phase 4 배포 준비 문서
- **FINAL_DEPLOYMENT_SUMMARY.md**: 최종 배포 요약

### 📦 04-archive/ - 아카이브
레거시 문서 및 참고용 문서들입니다.

- **UI_UPDATE_GUIDE.md**: UI 업데이트 가이드 (레거시)
- **geocodingmap.md**: 지오코딩 맵 관련 문서 (레거시)
- **pdr_appendix_wireframe.md**: 와이어프레임 부록 (레거시)

### 📄 루트 문서
- **PDR_Dashboard_v4.1_Final.md**: 프로젝트 최종 문서 (프로젝트 개요 및 완료 상태)

## 📖 문서 읽기 가이드

### 새로운 기능 계획을 확인하려면
→ `01-proposals/` 디렉토리 확인

### 특정 Phase의 완료 상태를 확인하려면
→ `02-completed/` 디렉토리에서 해당 Phase 문서 확인

### 배포 방법을 확인하려면
→ `03-deployment/` 디렉토리 확인

### 프로젝트 전체 개요를 확인하려면
→ `PDR_Dashboard_v4.1_Final.md` 확인

---

## 🔄 문서 업데이트 가이드

1. **새로운 제안서 작성 시**: `01-proposals/` 디렉토리에 추가
2. **Phase 완료 시**: `02-completed/` 디렉토리에 완료 보고서 추가
3. **배포 관련 문서 작성 시**: `03-deployment/` 디렉토리에 추가
4. **레거시 문서**: `04-archive/` 디렉토리로 이동
